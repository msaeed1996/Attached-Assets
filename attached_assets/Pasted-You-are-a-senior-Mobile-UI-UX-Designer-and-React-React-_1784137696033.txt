You are a senior Mobile UI/UX Designer and React/React Native developer. Redesign the Home Dashboard of my staffing app for brand-new users.

Context

This app is a staffing platform where workers sign up and wait to receive job invitations from recruiters.

During signup, users already complete:

Personal information
Skills
Work experience
Resume upload
Availability
Contact information

So the profile is already complete when they first log in.

However, a new user has:

No accepted jobs
No job invitations
No upcoming shifts
No approved hours
No alerts
No work history

Do NOT display empty cards that say "No data found", "No accepted jobs", or "No invitations".

Also do NOT show fake content, including:

Companies Hiring
Featured Employers
Nearby Jobs
Job Categories
Fake statistics

If there are no jobs available, the UI should still feel professional, informative, and engaging.

Goal

The dashboard should reassure users that:

Their account is active.
Their profile is complete.
They are ready to receive opportunities.
The staffing team is working to match them with jobs.

The screen should never feel empty.

Design Style

Create a premium modern mobile dashboard inspired by:

Uber Driver
Indeed Flex
Instawork
LinkedIn

Use:

White cards
Rounded corners (18px)
Soft shadows
Blue primary (#2563EB)
Green success (#22C55E)
Light gray background (#F5F7FA)
Clean typography
Plenty of whitespace
Modern icons from Lucide or Heroicons
Smooth card spacing

Design for a 375px mobile screen.

Empty State Rules

Never display:

No jobs found
No invitations found
No alerts
No data available

Instead, replace empty sections with useful information, onboarding guidance, status updates, or next steps.

Future State Logic

When the user receives their first invitation:

Replace the "Job Match Status" card with:

Job Invitations

When the user accepts a job:

Show:

Active Job
Check In
Upcoming Shift
Approved Hours

The dashboard should automatically evolve based on the user's activity.

Technical Requirements
Mobile-first responsive layout
Reusable card components
Smooth scrolling
Consistent spacing (16–24px)
Rounded buttons
Modern icon library
Accessible typography
Clean component hierarchy
Subtle animations (fade-in, pulse, hover, loading shimmer)
Production-ready React components
Final Goal

Design a dashboard that never feels empty, even when the user has no jobs. Every section should provide value by informing, guiding, or reassuring the user. The experience should communicate that the account is active, the profile is complete, and the platform is working to find the right opportunities—without showing placeholder data or misleading information. The UI should feel polished, trustworthy, and comparable to modern staffing applications.
